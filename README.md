# Wu.ai — AI 网页聚合客户端

把 **DeepSeek、豆包、通义千问、ChatGPT、Grok** 五家 AI 的网页版装进同一个桌面应用：

- **一键切换**：侧边栏品牌图标 / `Ctrl+1` ~ `Ctrl+5`，同一时刻只显示一家，各自页面独立运行
- **登录持久化**：每家独立的持久化 session 分区，登录一次，重启应用不掉线
- **密码本**：账号密码用系统级加密（Windows DPAPI）保存在本机；会话过期时打开密码本复制密码重新登录即可
- **页面净化**：自动屏蔽豆包"下载豆包工作台"/"关于豆包"页脚及下载图标、千问"订阅会员"/"下载电脑端"等推广元素；设置里可关闭，或给任意一家写自定义 CSS
- **笔记**：侧边栏一键打开的随手记（左列表右编辑，自动保存、搜索、删除），适合暂存与 AI 交互的记录文字
- **日 / 夜间模式**：侧边栏底部一键切换，网页界面实时跟随变色（夜间对网页做智能反色，图片视频还原原色），设置会记住
- **侧边栏拖动排序**：按住图标上下拖动即可调整顺序，快捷键编号跟随
- **省内存设计**：服务页面**惰性加载**（只加载你看的那家，首次切换才载入）；后台页面闲置后自动释放，**时长可在设置调整（默认 15 分钟，可关）**。实测从"全家常驻"的 ~2.3GB 降到 ~1.1GB
- **原生功能全保留**：深度思考、联网搜索、文件上传等都是各家原装网页能力，免费使用，无需 API key

## 使用

```
开发调试：npm run dev
构建安装包：npm run dist    →  release/Wu.ai Setup x.x.x.exe
类型检查：npm run typecheck
```

安装包双击安装后桌面生成 "Wu.ai" 快捷方式。托盘图标可随时找回主窗口。

## 代理说明

ChatGPT / Grok 需要代理才能访问。应用默认**跟随 Windows 系统代理**；也可以在 设置 → 通用 → 代理地址 里显式填写（如 `http://127.0.0.1:7890`）——填写后**独立于系统代理开关生效**，即代理软件只开着核心、Windows"系统代理"开关关闭时，应用内依然可以访问 ChatGPT/Grok（已实测验证）。国内三家不受代理影响。

## ChatGPT / Grok 的登录方式

Google 会主动拦截嵌入式浏览器（Electron）的 OAuth 登录（"此浏览器或应用可能不安全"），因此这两家推荐用**系统浏览器登录**：

1. 设置 → 对应服务 → **启动系统浏览器登录**：会打开一个专用 Chrome/Edge 窗口（独立配置目录，不影响你日常的浏览器）
2. 在里面用 Google 账号正常登录（真浏览器不会被拦截）
3. 回到应用点 **我已登录完成，导入会话**：应用自动收割登录态，页面重载即已登录，之后持久保存

备选方案：不用 Google 的话，ChatGPT 支持邮箱验证码 / Microsoft / Apple 登录，可在应用内直接完成；也可在系统浏览器登录后从 F12 复制 Cookie，用设置里的"导入 Cookie"粘贴导入。

## 项目结构

```
src/
├─ main/            # Electron 主进程
│  ├─ index.ts      # 窗口、WebContentsView 管理、托盘、单实例锁
│  ├─ sessions.ts   # persist 分区 + Chrome UA（session 持久化核心）
│  ├─ cleanup.ts    # 页面净化脚本（文字关键词 + 结构匹配，MutationObserver 兜底）
│  ├─ vault.ts      # 密码本（safeStorage/DPAPI 加密，仅显式查看/复制时解密）
│  └─ store.ts      # 设置（各家 URL、净化开关、自定义 CSS）
├─ preload/         # contextBridge IPC
├─ shared/          # 主进程/渲染层共享类型与「服务注册表」
└─ renderer/        # 壳 UI（React）：侧边栏、密码本面板、设置面板
```

**增加一家 AI**：在 `src/shared/services.ts` 的 `SERVICES` 数组加一条（id / 名称 / URL / 分区名 / 净化关键词），并在 `renderer/src/Sidebar.tsx` 的 `ICONS` 里放一个图标，重启即可。

## 内存开销说明

本应用内嵌的是完整网页，每开一家的内存开销与浏览器开一个标签相当（独立渲染进程）。省内存机制：

1. **惰性加载**——启动只加载上一次使用的服务，其他家首次点击才创建（约省 50% 内存）
2. **后台自动释放**——切走 10 分钟的页面整体销毁回收内存，重新点开自动重载（登录态保存在加密分区，云端会话不丢，重载约 2~5 秒）
3. 与浏览器对比：浏览器后台标签长时间闲置也会休眠/丢弃，行为一致；只要不同时常驻五家，内存不会比浏览器更费

## 说明与限制

- 各家登录 session 一般维持数天到数周；过期后需用密码本里的密码手动重登（验证码/短信必须人工）
- 净化规则按可见文字匹配推广元素，页面改版可能需要更新 `services.ts` 里的关键词；规则失效只影响美观不影响使用
- 密码本加密绑定当前 Windows 账户，换电脑/换账户后无法解密
- 仅登录需要人工操作，日常使用与普通浏览器无异；建议个人使用
- 已知修复：远程桌面/截屏环境下禁用了 Chromium 窗口遮挡计算（`CalculateNativeWinOcclusion`），否则 WebContentsView 会被误判遮挡而黑屏
